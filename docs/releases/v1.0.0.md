# Healwright v1.0.0 evaluation release

v1.0.0 turns the existing conservative locator-recovery runtime into a coherent local developer
product with a stable, inventoried public API. It is ready for external evaluation and carefully
scoped pilots; it is not presented as production-proven.

## First-user experience

- one `pnpm demo` path runs ordinary, safely healed, and ambiguous/rejected cases;
- `healwright demo --open` and `healwright view --open` open output only when explicitly requested;
- the static local report has a run outcome, evidence trust status, decision timeline, filters,
  candidate/signal comparison, and outcome-specific review guidance;
- the report is self-contained, escapes evidence, has a restrictive CSP, and uses no remote assets or
  telemetry.

## Stable contract

- machine-readable runtime/type/schema inventory at `api/public-api.json` with a stale-snapshot gate;
- documented SemVer, CLI, schema, Node, Playwright, and deprecation policy;
- Node 22 and 24 package-contract CI; `@playwright/test >=1.50.0 <2` peer range;
- consumer examples use only public package entrypoints.

## Delivery hardening

- every third-party GitHub Action is pinned to an immutable revision with a readable major-version
  comment;
- deterministic CycloneDX identity is accepted by GitHub SBOM attestation;
- package, SBOM, API snapshot, evidence, browser, governance, and demo checks remain in the release
  gate.

## Safety boundaries

Healing scope is unchanged. Healwright handles only proven locator drift for explicit `click`,
`fill`, `check`, and `selectOption` targets. It does not heal assertions, expected results,
authentication, business logic, APIs, test data, network failures, or product regressions. It never
silently rewrites source or registry files. Protected, weak, ambiguous, stale, or contradictory
evidence fails closed.

## Support and distribution

The full suite is Chromium-first with focused core safety qualification on Firefox and WebKit. The
repository release includes source and CI artifacts. No npm package was published as part of this
release.
