# Aegiloc v1.1.0

Released: 2026-08-24

v1.1.0 launches the Aegiloc identity and strengthens the conservative locator-recovery loop without
expanding healing into assertions, business outcomes, authentication, data, or network behavior.

## Highlights

- Exact pathname, unique-frame, and unique-container context gates isolate candidate discovery.
- Placeholder, title, and alt-text locators plus `uncheck`, `hover`, and `focus` expand the public
  wrapper while retaining per-action policy checks.
- Candidate-derived locator alternatives are ranked in Playwright-native order and verified for
  uniqueness and identity before entering a review proposal.
- Locator proposal schema v3 supports successful automatic evidence and protected
  `proposal-only` observations, with deterministic JSON Patch previews.
- Opt-in successful-primary fingerprint observations support independent-run, review-only
  fingerprint proposals.
- Evidence summary schema v2 and the static viewer expose historical healing, ambiguity,
  confidence, protected-attempt, drift-age, and recent-outcome signals per target.
- `createAegilocTest` provides a typed Playwright fixture with evidence, screenshot, provenance, and
  `PASSED_WITH_HEALING` wiring.
- The README, architecture, package identity, examples, CLI, schemas, CI metadata, and report are
  aligned under the Aegiloc name.

## Safety unchanged

- Primary Playwright behavior runs first.
- Only proven absence can enter recovery.
- Semantic incompatibility, low confidence, ambiguity, context mismatch, unstable revalidation, or
  protected execution fails closed.
- Assertions and expected results are never healable.
- No command applies proposals or silently edits source/registry files.
- No LLM, cloud service, database, Docker, OCR, or visual AI is required.

## Compatibility

Existing version-1 registries remain valid. New registry fields, locators, actions, fixture APIs,
and fingerprint APIs are additive. Locator proposal bundles move to schema v3 and evidence summaries
to schema v2; regenerate generated artifacts. See [migration guidance](../MIGRATION-v1.1.md) and the
[compatibility policy](../COMPATIBILITY.md).

## Distribution

This release is a GitHub source release. No npm package was published. The release workflow produces
reviewable package, SBOM, and provenance artifacts but does not authorize registry publication.
