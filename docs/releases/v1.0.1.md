# Healwright v1.0.1 evaluation release

v1.0.1 is a focused patch release for the stable v1 API. It corrects the public demo workflow so
the safest behavior is also the default behavior, and it aligns evaluator-facing release identity
and guidance. Healing logic, thresholds, schemas, and public APIs are unchanged.

## Safer demo reruns

- a clean `pnpm demo` still runs the deterministic local storefront and generates verified evidence;
- a repeat `pnpm demo` refuses to replace `test-results/realistic-demo` and leaves every existing
  artifact unchanged;
- after reviewing the prior report, `pnpm cli demo --force` is the explicit rerun path;
- browser opening remains deliberate through `pnpm cli demo --force --open`;
- an unavailable platform opener reports a copyable manual path without misreporting successful
  report generation as a failure.

## Evaluator polish

- troubleshooting uses the same repeat-run command as the CLI refusal message;
- the README names the generated report path directly;
- evaluator guidance warns that the unscoped npm name belongs to an unrelated project and keeps this
  GitHub release source-only;
- CLI help, the local report, package metadata, and current product documentation identify v1.0.1
  consistently;
- CI describes the realistic demo as an evaluation-release check rather than a technical preview;
- focused Firefox/WebKit qualification uses one worker locally and in CI so timing and performance
  contracts are measured consistently without relaxing any budget.

## Safety boundaries

Healwright still handles only proven locator drift for explicit `click`, `fill`, `check`, and
`selectOption` targets. It does not heal assertions, expected values, authentication, business
logic, APIs, test data, network failures, or product regressions. It never silently rewrites tests or
registries, and weak, ambiguous, protected, stale, or contradictory evidence continues to fail
closed.

## Support and distribution

The full suite remains Chromium-first with focused core safety qualification on Firefox and WebKit.
This GitHub source release does not publish Healwright to npm.
