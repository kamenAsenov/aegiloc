# Healwright v0.7.0 Technical Preview

Status: prepared in source for review; **not tagged, not published to npm, and not a GitHub Release**.

v0.7 strengthens the evidence and delivery chain around the existing conservative healing runtime.
It does not broaden which failures Healwright can heal.

## Highlights

- strict SHA-256 evidence manifests for canonical history and summary files;
- optional HMAC-SHA-256 authentication using external, permission-checked key files;
- explicit detection of missing, truncated, reordered, replaced, or mismatched evidence;
- `healwright attest` and `healwright verify` CLI commands;
- deterministic CycloneDX 1.6 SBOM generation and byte-reproducible package verification;
- dependency review plus GitHub provenance/SBOM attestations for `main` build artifacts;
- Firefox and WebKit core qualification alongside the full Chromium suite;
- a version-controlled 150-candidate median/p95 performance budget;
- documented key rotation, retention, cryptographic boundaries, and supply-chain limitations.

## Compatibility

- Node.js 20 or newer and pnpm 11 for repository workflows;
- Playwright Test `>=1.50.0 <2` as a peer dependency;
- registry, audit, evidence-summary, proposal, governance, and health schema versions remain 1;
- the new evidence-manifest schema begins at version 1;
- existing v0.6 runtime and CLI commands remain available.

## Security model

Authentication is optional and provider-neutral. Unsigned manifests detect change only when the
manifest itself is trusted. HMAC proves shared-key possession, not individual authorship or
non-repudiation. Keys never appear in manifests and must remain outside source and artifacts.

## Not yet production-ready

The API is still pre-1.0 and unpublished. Qualification covers the checked browser matrix rather
than arbitrary applications. There is no managed key service, public-key evidence signature,
long-running soak result, or production-adoption claim.

## Try it

```bash
pnpm install --frozen-lockfile
pnpm exec playwright install chromium firefox webkit
pnpm release:check
```

These commands create local generated artifacts only. A tag, GitHub Release, npm publication, and
merge remain separate maintainer decisions.
